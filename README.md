# Ableton (Barry bag)

Ableton Live session control, MIDI sequencing, audio analysis, and mixing tools.

## Tools

- `ableton_status` — check Ableton Live connection status
- `ableton_open` — open Ableton Live
- `ableton_setup` — initialize the Ableton control surface
- `ableton_get_session_info` — get current Live Set info (tempo, tracks, scenes)
- `ableton_get_track_info` — get details for a specific track
- `ableton_get_browser_categories` — list Ableton's browser categories
- `ableton_get_browser_items` — list items within a browser category
- `ableton_list_loadable_items` — list instruments/effects available to load
- `ableton_create_midi_track` — create a new MIDI track
- `ableton_create_audio_track` — create a new audio track
- `ableton_set_track_name` — rename a track
- `ableton_delete_track` — delete a track
- `ableton_set_track_mute` — mute/unmute a track
- `ableton_set_track_solo` — solo/unsolo a track
- `ableton_set_track_arm` — arm/disarm a track for recording
- `ableton_create_clip` — create a new MIDI clip in a session slot
- `ableton_set_clip_name` — rename a clip
- `ableton_add_notes_to_clip` — write MIDI notes into a session clip
- `ableton_get_clip_info` — get clip details
- `ableton_fire_clip` — launch a clip
- `ableton_stop_clip` — stop a clip
- `ableton_delete_clip_from_slot` — delete a clip from a session slot
- `ableton_set_clip_warping` — set clip warp mode and settings
- `ableton_create_arrangement_clip` — create a clip on the arrangement timeline
- `ableton_add_notes_to_arrangement_clip` — write MIDI notes into an arrangement clip
- `ableton_list_arrangement_clips` — list clips in the arrangement
- `ableton_duplicate_clip_to_arrangement` — duplicate a session clip to arrangement
- `ableton_create_audio_arrangement_clip` — create an audio clip in arrangement
- `ableton_load_browser_item` — load an instrument or effect from the browser
- `ableton_list_devices` — list devices on a track
- `ableton_list_device_parameters` — list a device's parameters
- `ableton_get_device_parameters` — get parameter values for a device
- `ableton_set_device_parameter` — set a device parameter value
- `ableton_delete_device` — remove a device from a track
- `ableton_setup_drum_processing` — set up drum processing chain
- `ableton_setup_mix_bus` — set up mix bus processing
- `ableton_set_tempo` — set project tempo
- `ableton_start_playback` — start playback
- `ableton_stop_playback` — stop playback
- `ableton_stop_all_clips` — stop all playing clips
- `ableton_undo_redo` — undo or redo
- `ableton_analyze_track_timbre` — analyze the spectral character of a track
- `ableton_compare_timbres` — compare timbres between tracks
- `ableton_detect_track_clashes` — detect frequency clashes between tracks
- `ableton_detect_and_fix_harshness` — detect and fix harsh frequencies
- `ableton_analyze_drum_features` — analyze drum sound features
- `ableton_match_timbre` — match a timbre to a target track
- `ableton_extract_and_load_drums` — extract and load drum samples

## Skills

- `mixing` — mixing fundamentals, EQ, compression, saturation, bass, drums, synths, vocals, harshness, frequency clash detection, and complete mix workflow
- `effects-chain` — building and managing audio effects chains
