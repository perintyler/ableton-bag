# QA: @barry/music ONNX Verification

Verify that the TypeScript ONNX implementations of stems.ts (demucs) and transcribe.ts (basic-pitch) produce correct results. All audio analysis is now pure TS + ffmpeg + ONNX with no Python dependencies.

## Requirements

- `node` (v20+)
- `ffmpeg` (for audio loading)
- `pnpm` (workspace package manager)
- `onnxruntime-node` npm package (installed in @barry/music)

## Setup

1. Install dependencies: `cd music && pnpm install`
2. Ensure test audio files exist (generated by test steps below)

## Test Steps

### 1. Unit tests pass

```bash
cd music && pnpm test
```

**Expected:** All tests pass (currently 40+). Zero failures.

### 2. TypeScript typechecks

```bash
cd music && pnpm typecheck
```

**Expected:** No errors.

### 3. Polyphonic transcription — baseline accuracy

Generate a test signal with two known pitches (440Hz + 880Hz) and verify basic-pitch detects them.

```bash
cd music && node --loader tsx -e "
  import { transcribePolyphonic } from './src/transcribe.js';
  const result = await transcribePolyphonic('/tmp/test_polyphonic.wav');
  const pitches = [...new Set(result.notes.map(n => n.pitch))].sort();
  console.log('Pitches:', pitches);
  console.log('Notes:', result.notes.length);
  const has440 = pitches.includes(69); // A4 = MIDI 69
  const has880 = pitches.includes(81); // A5 = MIDI 81
  console.log('440Hz (A4):', has440 ? 'FOUND' : 'MISSING');
  console.log('880Hz (A5):', has880 ? 'FOUND' : 'MISSING');
  if (!has440 || !has880) process.exit(1);
"
```

**Expected:** Both 440Hz (MIDI 69) and 880Hz (MIDI 81) detected. At least 2 notes found.

### 5. Stem separation — baseline verification

Run demucs on a short audio clip and verify 4 stems are produced.

```bash
cd music && node --loader tsx -e "
  import { separate } from './src/stems.js';
  const result = await separate({
    input: '$HOME/Downloads/Michael Jackson - Smooth Criminal (Official Video).mp3',
    outputDir: '/tmp/demucs_ts_test',
  });
  console.log('Model:', result.model);
  console.log('Stems:', [...result.stems.keys()]);
  const expectedStems = ['drums', 'bass', 'vocals', 'other'];
  for (const stem of expectedStems) {
    const path = result.stems.get(stem);
    if (!path) { console.log('MISSING:', stem); process.exit(1); }
    console.log(stem, ':', path);
  }
"
```

**Expected:** 4 stems produced (drums, bass, vocals, other). All files exist and are non-empty.

### 6. Stem separation — output quality

Verify stem outputs have reasonable spectral characteristics.

```bash
cd music && node --loader tsx -e "
  import { analyzeTimbre } from './src/analyze.js';
  // Verify drums stem has expected spectral characteristics
  const drums = await analyzeTimbre('/tmp/demucs_ts_test/drums.wav');
  console.log('Drums centroid:', drums.spectral.centroidHz, 'Hz');
  console.log('Drums brightness:', drums.summary.brightness);
  // Drums should have energy across a wide range
  if (drums.spectral.centroidHz < 500 || drums.spectral.centroidHz > 10000) {
    console.log('FAIL: drums centroid out of expected range');
    process.exit(1);
  }
  console.log('PASS: drum stem looks reasonable');
"
```

**Expected:** Drums spectral centroid between 500-10000 Hz. Non-empty output with reasonable spectral distribution.

### 7. Full pipeline — transcribe real audio end-to-end

```bash
cd music && node --loader tsx -e "
  import { transcribePolyphonic } from './src/transcribe.js';
  import { analyzeTimbre } from './src/analyze.js';

  // Analyze then transcribe
  const analysis = await analyzeTimbre('$HOME/Downloads/demucs_output/stems/bass.wav');
  console.log('Analysis centroid:', analysis.spectral.centroidHz, 'Hz');
  console.log('Analysis brightness:', analysis.summary.brightness);

  const transcription = await transcribePolyphonic('$HOME/Downloads/demucs_output/stems/bass.wav');
  console.log('Transcribed notes:', transcription.notes.length);

  if (analysis.spectral.centroidHz > 5000) {
    console.log('FAIL: bass centroid too high');
    process.exit(1);
  }
  if (transcription.notes.length < 50) {
    console.log('FAIL: too few bass notes detected');
    process.exit(1);
  }
  console.log('PASS');
"
```

**Expected:** Bass centroid < 5000 Hz. At least 50 bass notes transcribed.
